# John Melchor Brillante | Portfolio

A static portfolio site with no build step.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.

## Structure
- `index.html` page content
- `css/styles.css` styles, theme variables and responsive rules
- `js/main.js` animations and the Debt Eraser demo
- `assets/` images

## Deploy
Push these files to the root of the GitHub repository and turn on GitHub Pages (Settings, Pages, deploy from the main branch, root folder). All paths are relative, so it works as a project site.
